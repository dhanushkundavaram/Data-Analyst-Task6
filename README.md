# Task 6 – Sales Trend Analysis Using Aggregations

## Tools Used
- MySQL Workbench
- Custom Sample Dataset

## Objective
Use SQL queries to analyze monthly sales trends:
- Date-based grouping (Year/Month)
- Revenue aggregation
- Order volume analysis
- Sorting and filtering
- Top-performing time periods

## Files
- `task6_sql_queries.sql`

## 🚀 Sample Queries Covered
- Monthly revenue and order volume
- Top 3 months by sales revenue
- Grouping by year and month
- Use of EXTRACT(), SUM(), COUNT()
- ORDER BY and LIMIT usage

## Dataset Description
- Table: `online_sales`
- Columns:
  - `order_id` (INT)
  - `order_date` (DATE)
  - `product_id` (INT)
  - `amount` (DECIMAL)

## 💡 Key SQL Concepts Practiced
- Aggregate functions: `SUM()`, `COUNT(DISTINCT)`
- Time-based grouping using `EXTRACT()`
- Sorting with `ORDER BY`
- Filtering top results with `LIMIT`
